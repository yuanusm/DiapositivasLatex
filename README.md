# Diapositivas LaTeX: Guía de Estadística Descriptiva

Este repositorio contiene una presentación larga en LaTeX Beamer para estudiar Estadística Descriptiva, Números Índices, Probabilidades y Modelos Estocásticos en un solo documento integrado.

## Archivo principal

- `guia_estadistica_descriptiva.tex`: presentación completa e integrada con diapositivas sobre universo, población, muestra, censo, variables, escalas de medición, frecuencias, intervalos de clase, tablas de contingencia, representaciones gráficas, medidas de posición, cuantiles, medidas de dispersión, la Unidad 3 de números índices económicos y la Unidad 4 de teoría de probabilidades y análisis combinatorio, y la unidad de variables aleatorias y modelos estocásticos.

## Compilación

Para generar el PDF, ejecuta:

```bash
pdflatex guia_estadistica_descriptiva.tex
pdflatex me_3_numeros_indices.tex
```

Si tu distribución de LaTeX lo requiere, ejecuta el comando dos veces para estabilizar referencias y numeración.
